# SQL Coffee Shop (Интернет-магазин кофе)

Учебный проект по работе с SQL (SQLite + DBeaver) на примере интернет-магазина кофе.

## 1. Какие таблицы и зачем
- **products** — каталог товаров. Хранит название, описание, категорию, цену и уникальный артикул (SKU). В базе 100 товаров: 69 позиций кофе (с учетом весов и обжарки) и 31 позиция аксессуаров/дрипов/оборудования.
- **orders** — заказы. Хранит ID товара, количество и дату заказа. Связана с `products` через внешний ключ (`product_id`).

## 2. Ограничения и проверки
- `PRIMARY KEY` — уникальный ID для каждой записи.
- `UNIQUE` — артикул (SKU) не может повторяться.
- `NOT NULL` — название товара обязательно.
- `FOREIGN KEY` — заказ не может ссылаться на несуществующий товар.

## 3. Что показывают запросы (queries.sql)
- **INSERT** — добавление 3 ручных товаров и 1 массовая вставка.
- **UPDATE** — изменение цен (скидка на дрипы, правка по SKU, распродажа).
- **DELETE** — безопасное удаление тестовых записей (WHERE).
- **SELECT** — топ-5 самых дорогих товаров (ORDER BY, LIMIT).
- **Агрегация** — количество и средняя цена по категориям (GROUP BY, HAVING).
- **LIKE** — регистронезависимый поиск по артикулу (SKU) через `UPPER(sku) LIKE 'TED%'`.
- **JOIN** — сводная выборка заказов с суммой по категориям (`GROUP BY p.category`).
- **Безопасность** — пример опасного (конкатенация) и безопасного (параметризация `?`) кода.

## 4. Как запустить (4 шага)
1. Создать базу: `sqlite3 coffee_shop.db < schema.sql`
2. Заполнить данными: `python3 seed.py`
3. Открыть в DBeaver и выполнить запросы из `queries.sql`.
4. Проверить результаты и скриншоты в папке `screenshots/`.
